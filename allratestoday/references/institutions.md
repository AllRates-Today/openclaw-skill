## Response examples

Latest ECB table re-based to GBP:

```json
{"result":"success","base_code":"GBP","date":"2026-10-29","rates":{"USD":1.3317,"EUR":1.1965,"JPY":210.49}}
```

HMRC monthly table (home currency GBP as base, one row per quote currency, type `monthly`):

```json
{"bank":"hmrc","rate_date":"2026-10-01","cadence":"monthly","stale":false,
 "rates":[{"base":"GBP","quote":"AED","type":"monthly","value":4.9418}, ...]}
```

SAMA daily table (foreign currency as base, SAR as quote, type `reference`):

```json
{"bank":"sama","rate_date":"2026-10-29","stale":false,
 "rates":[{"base":"USD","quote":"SAR","type":"reference","value":3.75}, ...]}
```

Error (unknown code), HTTP 404:

```json
{"error":"No published table available for this source"}
```

## Cross rates inside one institution table

Find the home currency: the code that appears in most rows. For each currency X, compute units of home per 1 X from its row (`value` if X is base, `1/value` if X is quote). Then rate(A to B) = home_per_A / home_per_B.
