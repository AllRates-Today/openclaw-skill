# AllRatesToday skill for OpenClaw

Exchange rates, currency conversion and official central-bank / tax-authority rates for [OpenClaw](https://github.com/openclaw/openclaw) agents. Keyless by default.

```bash
openclaw skills install allratestoday
```

Skill source: `allratestoday/SKILL.md`. Data: https://allratestoday.com · Org: https://github.com/AllRates-Today
